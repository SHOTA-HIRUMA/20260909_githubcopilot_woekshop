# データモデル仕様

## 現在の実装状態

現時点では、バックエンドに永続化レイヤーおよびデータモデルクラスは実装されていない。  
本ドキュメントは、設計ドキュメントで定義されたデータモデルの仕様を記録するものである。

---

## 計画中のデータモデル

### Settings（タイマー設定）

タイマーの各種時間設定を保持するモデル。

| フィールド名 | 型 | 説明 |
|---|---|---|
| `work_minutes` | integer | 作業セッションの時間（分） |
| `short_break_minutes` | integer | 短休憩の時間（分） |
| `long_break_minutes` | integer | 長休憩の時間（分） |
| `long_break_interval` | integer | 長休憩を挿入するまでの作業セッション数 |

**デフォルト値（設計目標）**

| フィールド名 | デフォルト値 |
|---|---|
| `work_minutes` | 25 |
| `short_break_minutes` | 5 |
| `long_break_minutes` | 15 |
| `long_break_interval` | 4 |

---

### DailyProgress（日次進捗）

日付単位でのセッション完了数と集中時間を保持するモデル。

| フィールド名 | 型 | 説明 |
|---|---|---|
| `date` | string (YYYY-MM-DD) | 対象日付 |
| `completed_sessions` | integer | 完了したセッション数 |
| `focus_minutes` | integer | 累積集中時間（分） |

**管理ルール**

- `date` をキーとして日付単位で管理する。
- 日付が変わった場合は当日のデータを新規作成する（前日データは保持）。

---

## 現在の UI 表示値

現時点では、`index.html` に以下の静的な値がハードコードされている。

| 表示項目 | 静的値 |
|---|---|
| タイマー表示 | `25:00` |
| セッションラベル | `作業中` |
| 完了回数 | `4` |
| 集中時間 | `1時間40分` |
| プログレスリング進捗 | `72%`（CSS 変数 `--progress: 0.72`） |

これらはデータモデルが実装されたときに動的に更新される予定である。
